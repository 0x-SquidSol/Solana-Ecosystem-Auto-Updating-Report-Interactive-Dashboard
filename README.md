# Solana Ecosystem Report

An auto-updating report and interactive dashboard on the state of the Solana
network — built on pure Python standard library, with no API keys and no
third-party dependencies.

> **Status: work in progress.** Collectors, renderers, and automation are
> landing incrementally.

The engine, `heliostat`, gathers on-chain data directly over public Solana RPC
alongside public off-chain sources, then renders three outputs: an interactive
HTML dashboard, a human-readable Markdown report, and machine-readable JSON.
