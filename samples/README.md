# Sample outputs

Frozen copies of the generated Markdown and JSON reports from a real
mainnet run, kept stable for reference. The live versions regenerate
every 15 minutes in [`docs/`](../docs/), alongside the interactive
dashboard.

- [`report.md`](report.md) — the human-readable report
- [`report.json`](report.json) — the machine-readable report, including
  the full per-validator stake distribution and per-source status
